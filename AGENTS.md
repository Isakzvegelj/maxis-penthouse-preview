# maxis — Maxis Penthouse Bled website

## What this folder is
Static website for "Maxis Penthouse Bled" — a luxury penthouse short-stay
rental in Bled. Includes the live site, booking listing info, and PDF
generation.

## Key files
- `index.html`, `styles.css`, `bled-guide.html` — site
- `bled-penthouse.pdf` — penthouse info PDF (generated by `make_pdf.py`)
- `make_pdf.py` — PDF generator
- `booking-listing.md`, `LAUNCH.md`, `dns-import.txt` — launch/DNS/booking docs
- `CNAME`, `google8b1087122f047688.html` (search console), `robots.txt`, `sitemap.xml`
- `images/` — penthouse photo gallery
- `.netlify/` — Netlify deploy config

## Git / Deploy
- Remote: https://github.com/Isakzvegelj/maxis-penthouse.git
- Served via Netlify (CNAME + .netlify present).

## Conventions
- Static site + PDF generation. Commit to maxis-penthouse repo.
- Image gallery lives in `images/` and is updated often.
